# 📝 Changelog

## 1.1.0

- Show one to four cards as a vertical list or as pairs that wrap on narrow screens.
- Opt into top-left or bottom-right branding with an optional repository link.
- Animate card content with Fade, Rise, or Sweep. Set one effect for all cards or choose per card.
- Refresh the marked section in the profile README when the card selection, layout, or labels change.

## 1.0.0

- Generate overview, languages, projects, and activity cards in light and dark themes, plus a text report and README embed snippet.
- Use English by default, with built-in Brazilian Portuguese, Spanish, and French and support for custom messages.
- Include a local installer, a scheduled GitHub Actions updater, and a responsive bilingual preview.
- Test on Linux and Windows in GitHub Actions, including live generation from the public GitHub API on Linux.
